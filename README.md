# Arcade-Link
This is a EXE for OpenBOR Online called Arcade Link it's very simply to use and you can use Steam or Play through IP like Radmin VPN or Hamachi 

This was created with AI and was tested over Mortal Kombat Defenders of the Realm (4 Players) I have tested it with the other Mortal Kombat OpenBOR Games except Mortal Kombat The Chosen One that game seem to be big I will make more updated for everyone 

I will test other games to see if it will do justice against of OpenBOR Games.

So be mindful this is a Early Test for everyone so don't expect it to be perfect at all.  I love the OpenBOR Community so I wanna do something nice for everyone.

Maybe this will be helpful for people to test games easily.
